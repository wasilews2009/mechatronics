§0 Короткі теоретичні відомості

Матеріал для повторення перед виконанням завдань (лекції №1–3). Розгорніть потрібний блок.

Етапи еволюції мехатроніки▶
  • Античність та Середньовіччя — Ктесібій, Архімед, Херон, аль-Джазарі, да Вінчі.
  • Новий час та Просвітництво — Вокансон, Жаке-Дро, Жаккард, Беббідж.
  • Кібернетична революція (1920–1950-ті) — Чапек, Азімов, Вінер, Мінорський, «кібернетичний зоопарк».
  • Перші промислові роботи (1950–1970-ті) — Девол, Енгельбергер, Unimate, KUKA FAMULUS, ABB IRB 6.
  • Сучасність — колаборативні роботи, гуманоїди, Industry 4.0, AI-оптимізація.
Архітектура мехатронної системи▶

Чотири базові підсистеми: механічна, електрична/електронна, сенсорна, інформаційна. Ієрархія керування: стратегічний → тактичний → виконавчий рівні.

Покоління мехатронних модулів▶

I рівень — мотор-редуктор. II рівень — інтеграція датчиків (сервопривод з енкодером). III рівень — інтелектуальні модулі руху (ІММР) з власним контролером і цифровою шиною.

Програмування рухів: KRL і RAPID▶

Типи рухів: PTP (Point-to-Point, KRL) / MoveJ (RAPID) — швидкий рух у просторі суглобів; LIN / MoveL — лінійний рух TCP; CIRC / MoveC — рух по дузі; SPLINE — гладка траєкторія через кілька точок.

Координатні системи: WORLD (цех), BASE (робоча зона), ROBROOT (основа робота), TOOL/FLANGE (інструмент, TCP).

04 Програмування траєкторії «Barista Move»

Форма: індивідуально · Час: 35 хв · Мета: закріпити типи рухів промислових роботів і координатні системи.

Алгоритм побудови програми (ментальна карта)

Технологічна задача — операція «Капучино»

HOME

Початкове положення робота.

A · COFFEE_MACHINE

Підхід до кавомашини (горизонтальна площина, без перешкод) — PTP.

B · CUP_PICK

Захват чашки, потрібна точність — LIN.

C · POUR

Наливання кави, лінійна траєкторія без розбризкування — LIN.

D · CLIENT

Видача чашки клієнту — LIN, потім повернення в HOME — PTP.

Блок безпеки

Силомоментний/лазерний датчик зупиняє робота при появі перешкоди: IF $TORQUE_AXIS[3] > MAX_TORQUE THEN STOP.

🧪 Симуляція траєкторії робота-баристи

Натисніть «Старт», щоб прогнати програму. TCP рухається по прямій під час LIN і по вигнутій траєкторії суглобів під час PTP. Відповідний рядок коду підсвічується синхронно.

Готово до запуску…
DEF BaristaMove() ; Оголошення точок (координати умовні) DECL E6POS HOME, A, B, C, D HOME = {X 0, Y 0, Z 400, A 0, B 0, C 0} A = {X 300, Y 200, Z 300, A 0, B 90, C 0} B = {X 300, Y 200, Z 150, A 0, B 90, C 0} C = {X 300, Y 200, Z 180, A 0, B 90, C 0} ; точка наливання D = {X 500, Y 400, Z 200, A 0, B 90, C 0} ; видача клієнту PTP HOME Vel=100% PDAT1 ; початкове положення PTP A Vel=100% PDAT2 ; швидкий підхід LIN B Vel=0.5 m/s CPDAT1 ; точне позиціонування LIN C Vel=0.2 m/s CPDAT2 ; наливання, повільно WAIT SEC 3 ; час наливання LIN D Vel=0.3 m/s CPDAT3 ; перенесення клієнту PTP HOME Vel=100% PDAT1 ; повернення END

Завдання: письмово поясніть у зошиті, чому обрано саме такий тип руху та швидкість на кожному переході, спираючись на симуляцію вище.

Глосарій

Мехатроніка
Міждисциплінарна галузь, що інтегрує механіку, електроніку та інформатику для створення систем із синергетичним ефектом.
Синергетичний ефект
Якісно нова властивість системи, недосяжна для її окремих підсистем поза інтеграцією.
ІММР
Інтелектуальний мехатронний модуль руху — модуль III рівня з вбудованим контролером і цифровою шиною зв'язку.
PTP / MoveJ
Point-to-Point — рух у просторі суглобів, найшвидший, траєкторія TCP не контролюється.
LIN / MoveL
Лінійний рух TCP по прямій між двома точками з контрольованою швидкістю.
CIRC / MoveC
Рух TCP по дузі кола через проміжну точку.
WORLD / BASE / TOOL / FLANGE
Ієрархія координатних систем: глобальна цехова, робоча зона, інструмент (TCP), фланець кріплення інструмента.
Повторюваність vs точність
Повторюваність — розкид позицій при поверненні в ту саму точку; точність — відхилення від заданої координати. Для зварювання кузова критична повторюваність.
Обернена кінематика
Обчислення кутів суглобів за заданою позицією TCP; задача нелінійна і може мати до 8 розв'язків для 6-вісного робота.
RaaS
Robot-as-a-Service — оренда робота з оплатою за використання замість купівлі, знижує поріг входу для малого бізнесу.
Електронний кулачок (Electronic Cam)
Програмна імітація механічного кулачкового механізму синхронізації рухів, що замінює фізичні кулачки та важелі.
Кобот
Колаборативний робот, розрахований на безпечну спільну роботу з людиною без огорож, зазвичай із силомоментними датчиками.
